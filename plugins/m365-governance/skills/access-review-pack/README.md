# access-review-pack

Builds the quarterly access review package from saved Graph exports: privileged role holders with last sign-in, app registration owners, owners of sensitive groups, guests per group and credentials about to expire, as a reviewer checklist and a sign-off CSV whose decision column stays blank for the reviewer.

How to run it, what to export and how to read the result: [SKILL.md](SKILL.md). Every option: `python3 scripts/access_review_pack.py --help`.

## Sample

Run from the repository root on the committed fixture (an example tenant with planted problems; every name, address and id in it is invented). Exit code 0.

```bash
python3 plugins/m365-governance/skills/access-review-pack/scripts/access_review_pack.py tests/fixtures/access-review/tenant --config tests/fixtures/access-review/config.yaml --as-of 2026-10-04
```
