# teams-and-groups-sprawl

Reports Teams and Microsoft 365 group sprawl: ownerless and single-owner groups, guest owners or members, public and inactive teams, empty groups, naming violations and groups missing an expiration policy, with owners proposed from member managers as a draft.

How to run it, what to export and how to read the result: [SKILL.md](SKILL.md). Every option: `python3 scripts/groups_sprawl.py --help`.

## Sample

Run from the repository root on the committed fixture (an example tenant with planted problems; every name, address and id in it is invented). Exit code 1 (findings at or above --fail-on).

```bash
python3 plugins/m365-governance/skills/teams-and-groups-sprawl/scripts/groups_sprawl.py tests/fixtures/groups/tenant --config tests/fixtures/groups/config.yaml --as-of 2026-10-04
```
