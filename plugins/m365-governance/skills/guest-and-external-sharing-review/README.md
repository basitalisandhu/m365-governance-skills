# guest-and-external-sharing-review

Reviews guest accounts and external sharing settings: guests from blocked domains or in sensitive groups, stale and unaccepted invitations, anyone links and links that never expire, guest resharing and open Teams external access, with a per-guest access map and a draft removal list.

How to run it, what to export and how to read the result: [SKILL.md](SKILL.md). Every option: `python3 scripts/external_sharing.py --help`.

## Sample

Run from the repository root on the committed fixture (an example tenant with planted problems; every name, address and id in it is invented). Exit code 1 (findings at or above --fail-on).

```bash
python3 plugins/m365-governance/skills/guest-and-external-sharing-review/scripts/external_sharing.py tests/fixtures/external-sharing/tenant --config tests/fixtures/external-sharing/config.yaml --as-of 2026-10-04
```
