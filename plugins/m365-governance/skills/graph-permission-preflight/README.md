# graph-permission-preflight

Compares the Graph permissions an app, connector or MCP server requests or holds with a needs manifest of what it actually uses, flags high-risk, .All, write-where-read-suffices and unused grants, and proposes a least-privilege set.

How to run it, what to export and how to read the result: [SKILL.md](SKILL.md). Every option: `python3 scripts/permission_preflight.py --help`.

## Sample

Run from the repository root on the committed fixture (an example tenant with planted problems; every name, address and id in it is invented). Exit code 1 (findings at or above --fail-on).

```bash
python3 plugins/m365-governance/skills/graph-permission-preflight/scripts/permission_preflight.py tests/fixtures/preflight/over-broad --needs tests/fixtures/preflight/over-broad/needs.yaml --as-of 2026-10-04
```
