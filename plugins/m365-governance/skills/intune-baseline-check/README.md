# intune-baseline-check

Checks an Intune estate against a device baseline: non-compliant, stale, unencrypted, jailbroken and outdated devices, personal devices, unassigned compliance policies, platforms missing baseline controls and the no-policy-means-compliant setting, per platform.

How to run it, what to export and how to read the result: [SKILL.md](SKILL.md). Every option: `python3 scripts/intune_baseline.py --help`.

## Sample

Run from the repository root on the committed fixture (an example tenant with planted problems; every name, address and id in it is invented). Exit code 1 (findings at or above --fail-on).

```bash
python3 plugins/m365-governance/skills/intune-baseline-check/scripts/intune_baseline.py tests/fixtures/intune/estate --config tests/fixtures/intune/config.yaml --as-of 2026-10-04
```
