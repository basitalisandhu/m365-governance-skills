# copilot-oversharing-readiness

Scores a tenant's readiness for a Copilot rollout from SharePoint and Purview exports: Everyone grants, anyone and organisation-wide links, sites with no label or no owner, and DLP coverage, with a fix list per site owner.

How to run it, what to export and how to read the result: [SKILL.md](SKILL.md). Every option: `python3 scripts/copilot_readiness.py --help`.

## Sample

Run from the repository root on the committed fixture (an example tenant with planted problems; every name, address and id in it is invented). Exit code 1 (findings at or above --fail-on).

```bash
python3 plugins/m365-governance/skills/copilot-oversharing-readiness/scripts/copilot_readiness.py tests/fixtures/copilot/tenant --as-of 2026-10-18 --org-links 1
```
